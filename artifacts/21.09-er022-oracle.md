## Приложение: скрипт замены

Замена была не ручной: скрипт ниже прошёл по всем `.py` рабочей зоны за один
проход, и счёт сошёлся (`theta` 1166 → `psi` 1166, `phi` 360 → `theta` 360,
`θ` 52 → `ψ` 52).

**Второй раз его запускать нельзя:** он не идемпотентен — на уже
переименованном коде он уедет ещё на шаг и схлопнет наклон с колесом. Это
запись того, что было сделано, а не инструмент на каждый день.

Единственные оставшиеся `phi` в рабочей зоне — в `examples/cost_sweep.py`:
там они названы нарочно, чтобы узнавать старые `.npz`.

```python
# -*- coding: utf-8 -*-
"""ER-022: theta -> psi (наклон), phi -> theta (колесо) в рабочей зоне.

Замена идёт через плейсхолдеры: наивное "phi -> theta" после "theta -> psi"
схлопнуло бы обе переменные в одну.  Регистры разведены явно, чтобы I_THETA
и THETA_FALL не уехали мимо.  Исключение -- матрица перехода `Phi` (Φ) в
sensor.py и test_imu_correlation.py: это дискретная матрица процесса смещения,
а не угол колеса, и её имя остаётся.
"""
import os, re, sys, collections

ROOTS = ("wpend", "tests", "examples")
KEEP = "\x01"          # защищённая Φ
P = {"theta": "\x02", "Theta": "\x03", "THETA": "\x04", "θ": "\x05"}
Q = {"phi": "\x06", "PHI": "\x07"}
BACK = {"\x02": "psi", "\x03": "Psi", "\x04": "PSI", "\u0005": "ψ",
        "\x06": "theta", "\x07": "THETA", KEEP: "Phi"}

def convert(t):
    t = re.sub(r"\bPhi\b", KEEP, t)          # Φ -- матрица перехода, не угол
    for a, b in P.items():
        t = t.replace(a, b)
    for a, b in Q.items():
        t = t.replace(a, b)
    for a, b in BACK.items():
        t = t.replace(a, b)
    return t

def count(t):
    return collections.Counter({w: len(re.findall(w, t))
                                for w in ("theta", "phi", "psi", "θ", "ψ")})

if __name__ == "__main__":
    dry = "--apply" not in sys.argv
    before, after, touched = collections.Counter(), collections.Counter(), 0
    for root in ROOTS:
        for d, dirs, files in os.walk(root):
            dirs[:] = [x for x in dirs if x != "__pycache__"]
            for f in files:
                if not f.endswith(".py"):
                    continue
                p = os.path.join(d, f)
                t = open(p, encoding="utf-8").read()
                n = convert(t)
                before += count(t); after += count(n)
                if n != t:
                    touched += 1
                    if not dry:
                        open(p, "w", encoding="utf-8", newline="").write(n)
    print("файлов изменено:", touched, "| режим:", "проба" if dry else "ЗАПИСЬ")
    print("до :", dict(before))
    print("после:", dict(after))
```

## 4. Второй заход: перевод `docs/*.md`

Решение Глеба 21.09: `psi` под наклон выбрано осознанно (так в статье, на
которую опирается работа), от старого концепта с `psi` на колесе отказались —
значит документы переводим, а не оставляем историческими.

Переведены `docs/Key_Formulas.md`, `docs/accel_compensation.md`,
`docs/imu_noise.md`. Формулы и нумерация параграфов не тронуты, ссылки `§…` из
докстрингов кода проверены и действительны (`§1.2`, `§1.3`, `§1.4`, `§2.2`,
`§3`, `§3.2` — все на месте).

| файл | `\theta` → `\psi` | `\varphi` → `\theta` | греческие в тексте | `\varepsilon` |
|---|---|---|---|---|
| `Key_Formulas.md` | 360 → 360 | 74 → 74 | — | 0 |
| `accel_compensation.md` | 126 → 126 | 20 → 20 | — | 6, не тронут |
| `imu_noise.md` | 1 → 1 | 1 → 1 | `θ` 2 → `ψ` 2, `φ` 3 → `θ` 3 | 0 |

**Ловушка, которой нет в коде.** Внутри `\varphi` сидит подстрока `phi`:
наивная замена сделала бы `\vartheta` — команду, рисующую другую букву.
Поэтому `\varphi` уходит в плейсхолдер первым. Обратная сторона: внутри
`\varepsilon` сидит `psi`, но `psi` мы только вставляем, а не ищем, так что
команда цела — в сверке счёта её надо помнить, иначе числа не сойдутся.

**Вторая ловушка, найденная при вычитке.** В `docs/imu_noise.md` строка
марковского смещения написана как `b_k = φ·b_{k−1} + …`, `φ = e^{−dt/tau}` —
это **коэффициент перехода**, тот самый `Phi` из `IMUSensor`, а не угол колеса.
Механический перевод сделал из него `θ`, то есть новый угол колеса: буква
совпала бы со смыслом, которого у неё нет. Возвращено в `φ`, рядом стоит
пояснение. Ровно тот же случай, что `Phi` в `sensor.py` в первом заходе —
счёт символов такое не ловит, ловит только чтение.

Скрипт перевода (тоже не идемпотентен, второй раз запускать нельзя):

```python
# -*- coding: utf-8 -*-
"""ER-022, второй заход: перевод docs/ в новую нотацию (решение Глеба 21.09).

Отличие от кода: в документах угол колеса записан как `\\varphi`, а внутри
этой команды сидит подстрока `phi`. Наивная замена сделала бы из неё
`\\vartheta`, поэтому `\\varphi` уходит в плейсхолдер первой. `\\varepsilon`
трогать нельзя вовсе -- внутри него сидит `psi`, но мы `psi` только вставляем,
а не ищем, так что он в безопасности; в сверке счёта его надо помнить.
"""
import re, sys, collections

W = "\x01"   # колесо: \varphi и φ
T = "\x02"   # наклон: θ
Wg = "\x03"  # колесо: φ

def convert(t):
    t = t.replace("\\varphi", W).replace("φ", Wg).replace("θ", T)
    t = t.replace("theta", "psi").replace("Theta", "Psi").replace("THETA", "PSI")
    t = t.replace("phi", "theta").replace("Phi", "Theta").replace("PHI", "THETA")
    return t.replace(W, "\\theta").replace(Wg, "φ").replace(T, "ψ") \
            .replace("φ", "θ")

def counts(t):
    keys = ("\\\\theta", "\\\\psi", "\\\\varphi", "\\\\varepsilon",
            "θ", "φ", "ψ", "theta", "phi", "psi")
    return {k.replace("\\\\", "\\"): len(re.findall(k, t)) for k in keys}

if __name__ == "__main__":
    apply = "--apply" in sys.argv
    for p in [a for a in sys.argv[1:] if a.endswith(".md")]:
        t = open(p, encoding="utf-8").read()
        n = convert(t)
        print(p)
        print("  до   :", counts(t))
        print("  после:", counts(n))
        if apply:
            open(p, "w", encoding="utf-8", newline="").write(n)
            print("  записан")
```
