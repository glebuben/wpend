# wpend

Минимальная лаборатория динамики и управления. Пять слоёв, один прогон,
одна зависимость (numpy).

```
System      dx/dt = f(t, x, u)   + ограничение мотора u_bounds
Sensor      x, u₋₁ ──▶ y        что реально видно
Estimator   y  ──▶ x̂             что мы думаем о состоянии
Controller  x̂ ──▶ u             что мы хотим приложить
Integrator  (f, x, u, dt) ──▶ x'

rollout(...) ──▶ Trajectory(t, x, u)
```

Всё, что идёт после прогона — графики, анимация, метрики, обучение — читает
только `Trajectory`.

Датчику передаётся ПРОШЛОЕ управление: акселерометр меряет удельную силу, в
которую входит ускорение корпуса, то есть момент. Модель ошибки инерциального
датчика — `IMUSensor`.

## Быстрый старт

Окружение заморожено: `.python-version` задаёт интерпретатор, `uv.lock` —
версии пакетов. `uv sync` воспроизводит и то, и другое.

```bash
uv sync --extra dev            # CPython 3.12.13 + numpy/pytest/pygame из uv.lock
uv run pytest tests -q
uv run python examples/balance.py
```

## Окно исследователя: колёсный маятник

Окно `wpend.viz.explorer` строит карту начальных условий колёсного маятника
(наклон корпуса `psi0` × скорость наклона `dpsi0`). Для каждой клетки оно
прогоняет замкнутый контур «машина → датчики → оцениватель → регулятор» и
красит клетку по исходу. Справа показаны анимация машины и графики выбранной
клетки.

### Запуск

```bash
uv sync --extra dev        # один раз: numpy, pygame, scipy, numba, pytest из uv.lock
uv run python -m wpend.viz.explorer --main bang-eps-ell --horizon 15 --grid 21
```

* `--main bang-eps-ell` — основной регулятор, он красит карту: реле по
  сепаратрисе → при `|psi| < eps` мягкий ЛКР → базовый ЛКР в его эллипсоиде.
* `--horizon 15` — сколько секунд моделировать каждую клетку.
* `--grid 21` — сетка 21 × 21 = 441 начальное условие.

Вся карта считается заранее, одним векторным прогоном. По умолчанию регулятор
видит машину через **фильтр Калмана** (`--estimator kalman`): ИДУ (акселерометр
+ гироскоп с шумом MPU-6050) и моторный энкодер. Команда выше на 2 ядрах
считается около 18 с. При первом запуске numba несколько секунд компилирует
ядро фильтра, дальше оно берётся из кэша. Без numba (`uv sync --extra viz`)
окно работает так же, только фильтр считается медленнее.

### Полезные варианты

```bash
uv run python -m wpend.viz.explorer --help                         # все ключи
uv run python -m wpend.viz.explorer --main bang-eps-ell --compare lqr        # второй регулятор поверх
uv run python -m wpend.viz.explorer --main bang-eps-ell --estimator ideal    # регулятор видит истину
uv run python -m wpend.viz.explorer --main bang-eps-ell --u-max 5            # предел момента, Н·м
uv run python -m wpend.viz.explorer --main bang-eps-ell --world wind         # мир с ветром
uv run python -m wpend.viz.explorer --main bang-eps-ell --chip raw --bias-prior calibrate  # сырой чип + стоянка
uv run python -m wpend.viz.explorer --no-precompute                          # считать клетку по клику
```

| ключ | что задаёт | по умолчанию |
|---|---|---|
| `--main`, `--compare` | регуляторы: `lqr`, `bang-eps-ell`, `bang-energy-ell` | `bang-energy-ell`, нет |
| `--estimator`, `--estimator-compare` | что видит регулятор: `ideal`, `comp`, `gyro`, `acc`, `kalman` | `kalman`, нет |
| `--horizon`, `--dt`, `--stride` | горизонт, шаг интегрирования, каждый какой кадр хранить | 5 с, 1 мс, 10 |
| `--grid`, `--psi-max`, `--dpsi-max` | размер и границы карты (без явных границ подгоняются под `u_max`) | 21 |
| `--u-max` | предел момента мотора, Н·м (`inf` — без предела) | 3 |
| `--sigma-a`, `--sigma-g`, `--b0-g`, `--counts` | шумы ИДУ, смещение гироскопа, метки энкодера | MPU-6050, 2048 |
| `--world`, `--sigma-w`, `--tau-w` | мир: `clean` или `wind` (случайный толчок) | `clean` |
| `--world-params`, `--nominal-params` | физика мира и то, что о ней знают регулятор и фильтр (`mb=10,mw=1,l=1,r=0.3`) | одинаковые |
| `--chip`, `--bias-prior` | чип ИДУ (`calibrated`/`raw`) и априор смещений фильтра (`code`/`calibrate`) | `calibrated`, `code` |
| `--kf-w`, `--kf-q-acc`, `--kf-iter`, `--kf-drift` | модель возмущения в фильтре, шум процесса, итерации, уход смещений | `matched`, 1e-4, 1 |

### Что на экране

* **Карта (слева).** Синий — корпус удержан, красный — упал вперёд, фиолетовый —
  назад. Зелёная кривая — граница восстановимости, оранжевая — линия
  переключения реле (`C`). Клик по клетке выбирает её.
* **Справа** — машина и графики выбранной клетки: `psi(t)`, `u(t)` (или толчок
  `w(t)`, клавиша `P`), полоса фаз регулятора. Розовым поверх — оценка
  фильтра.
* **Дорожка времени** под графиками выбирает кадр уже посчитанной траектории.
  Ручку можно тянуть мышью, стрелки `←`/`→` сдвигают на кадр, с `Shift` — на 10.
* **Виды фильтра Калмана** (кнопки над машиной) закрывают правую половину:
  * `V` — фазовая плоскость `(psi, dpsi)`: истина, оценка и эллипс 1σ ковариации `P`;
  * `H` — показания датчиков `y` и предсказание `h(x̂⁻, u)` против чистого `h(x, u)`;
  * `B` — смещения ИДУ: ошибка оценки против `√P`, и NEES по всей карте
    (честен ли фильтр: среднее ≈ 3).

### Клавиши

| клавиша | действие |
|---|---|
| `1`, `2`, `3` | основной регулятор: LQR, bang → eps → ell, bang-energy → ell |
| `Shift`+`1..3`, `Shift`+`0` | регулятор сравнения / убрать сравнение |
| `E`, `Shift`+`E` | следующий оцениватель / следующий оцениватель сравнения |
| `[`, `]`, `L` | предел момента −/+, снять или вернуть предел |
| `ПРОБЕЛ`, `R` | пауза, проиграть с начала |
| `←`, `→` | кадр назад/вперёд (`Shift` — 10 кадров) |
| `W` | мир: чистый ↔ ветер |
| `M`, `K`, `N`, `S` | панели: физика мира и номинала, фильтр Калмана, корреляции шумов, веса ЛКР и горизонт |
| `V`, `H`, `B` | виды фильтра: эллипс, показания, смещения |
| `P` | график `u(t)` ↔ толчок `w(t)` |
| `C` | показать/скрыть линию переключения реле |
| `T` | измерить оптимальную постоянную комплементарного фильтра (секунды) |
| `Esc`, `Q` | выход |

В панелях: `Tab`/`↑`/`↓` — поле, `Enter` — применить (карта пересчитается), `Esc` — закрыть.

## Версии

`requires-python` остаётся `>=3.10`: библиотека совместима с 3.10+. Но
разработка и проверки идут на одной сборке — `.python-version` = `3.12.13`,
uv скачает именно её. Пакеты приколочены в `uv.lock` (он коммитится).

```bash
uv lock --upgrade              # осознанно обновить всё
uv lock --upgrade-package numpy
uv sync --extra dev            # привести .venv в соответствие с локом
```

## Что где

```
wpend/            ядро: пять слоёв + rollout
wpend/models/     конкретные системы: маятник, колёсный маятник
wpend/viz/        окно pygame и классификация исходов (читает только Trajectory)
tests/            оракулы: порядок схем, сохранение энергии и первого интеграла
examples/         запускаемые сценарии
src/, scripts/    код второго семестра (numpy), достался от master, не трогаем
```

Прошлая версия библиотеки (`dynlab`) живёт на ветке `refactor/architecture` и
сюда не переносится.
