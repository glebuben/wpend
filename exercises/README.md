# Упражнения по wpend

Четыре скрипта, каждый запускается сам по себе и сам себя проверяет. Порядок
имеет значение: каждый следующий трогает более глубокий слой.

```bash
python exercises/00_warmup.py       # ~10 мин  собрать контур из готовых блоков
python exercises/01_controller.py   # ~25 мин  свой Controller
python exercises/02_integrator.py   # ~25 мин  свой Integrator
python exercises/03_system.py       # ~30 мин  своя System
```

Ищи в файлах `TODO` — заполнять надо только их. Скрипт печатает `[PASS]` /
`[FAIL]` по каждой проверке и объясняет, что именно она значит; у провалившихся
есть подсказка.

## Что проверяют проверки

Не совпадение с моим выводом — это ничего не доказывало бы. Каждая опирается на
утверждение, верное независимо от твоего кода:

| Упражнение | Оракул |
|---|---|
| 00 | без управления падает, с управлением — нет; энергия при этом **растёт** ровно до `m·g·l` |
| 01 | твой ПД совпадает с `LinearFeedbackController` до `1e-12`; при `kp < mgl` удержания нет ни при каком `kd` |
| 02 | **измеренный** порядок сходимости равен 2 (наклон `log(ошибка)` по `log(dt)`) |
| 03 | при `cq = 0` совпадает с библиотечной моделью; энергия монотонно убывает; `f(пачка)` построчно равна `f(одно)` |

Оракул в 02 — самый показательный: он ловит и опечатку в коэффициентах, и
случайно написанного Эйлера, чего не поймает никакая проверка «результат похож
на правду».

## Если застрял

Сначала перечитай подсказку у провалившейся проверки — она обычно называет
конкретную ошибку. `SOLUTIONS.md` рядом; открывай его после того, как честно
посидел минут двадцать, иначе упражнение превращается в чтение.
